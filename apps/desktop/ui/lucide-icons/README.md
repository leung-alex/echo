# Lucide user icon assets

This directory contains the static SVG catalog from the pinned `lucide-static` package.

- Package: `lucide-static`
- Version: `1.47.0`
- Registry integrity: `sha512-yWIrkdXc688Feq5VjOktsKmV5Ikc7y5Nu3rrdtbr8nWjkJWk8QlnZfVtIak22Af+fNhZ7k4cTJpZo1zmj7X5sA==`
- Source: https://github.com/lucide-icons/lucide
- License: ISC; see `LICENSE.txt`

The assets are compiled into Echo and do not require React, JavaScript, npm, or a network connection at runtime. The generator and catalog metadata are kept in `tools/icons/generate_lucide.py` and `apps/desktop/src/lucide_icons.rs`.
