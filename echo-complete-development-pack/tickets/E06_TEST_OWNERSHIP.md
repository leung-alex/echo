# E06 — Test Ownership Extraction

## Objective

Complete `Echo` test ownership according to `docs/06_TEST_OWNERSHIP.md`.

## Required work

- create/update `docs/TEST_OWNERSHIP_MAP.md`,
- inventory legacy product-owned Culsans tests,
- migrate/rewrite/replace them against `Echo`,
- migrate only required helpers/fixtures,
- keep equivalent confidence level,
- ensure no destination acceptance starts Culsans,
- run destination-local unit/component/integration tests,
- commit this stage separately.

## Exit criteria

- no unexplained product-owned legacy test remains,
- destination acceptance is runnable from this repository,
- local P06 gates pass.
